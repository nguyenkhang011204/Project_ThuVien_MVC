# Library Management System - Custom PHP MVC

A library management system developed as an academic project using
PHP, MySQL, and a custom MVC architecture built from scratch.

## 📌 Project Overview

This project was developed as part of a PHP MVC programming course.

Instead of relying on an existing PHP framework, the project focuses on
building the core MVC architecture from scratch to gain a deeper
understanding of how MVC-based web applications work.

The main focus of the project is the application's architecture,
including routing, controllers, models, views, and database interaction.

## 🎯 Project Objectives

- Understand the fundamental principles of the MVC architecture.
- Build a lightweight MVC structure using native PHP.
- Apply Object-Oriented Programming principles.
- Understand how HTTP requests are routed and processed.
- Separate business logic, data access, and presentation layers.
- Practice working with MySQL databases using PHP.
- Implement basic CRUD operations.
